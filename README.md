# SpriteGame
Backend for a browser based 2d sprite RPG.
Spiritual successor to my (failed) collaborative project, [IRL_RPG](https://github.com/Donderstal/IRL_RPG) and its [Mapmaker](https://github.com/Donderstal/Mapmaker-Svelte3).

## Aspire
This project is setup with Aspire as an orchestrator.
[Get aspire](https://aspire.dev/) and run the application from the /src folder with the following command
```sh
aspire run
```
